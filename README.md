# Room Booking API

Room booking API with a separate frontend app.

## Structure

```text
room-booking/
  backend/    Express + Prisma + Swagger API
  frontend/   Client app (to be scaffolded)
```

## Backend

```bash
cd backend
npx tsx src/server.ts
```

- API: http://localhost:3000
- Swagger: http://localhost:3000/api-docs

## Frontend

Scaffold inside `frontend/` when you start the UI (Vite, etc.).
